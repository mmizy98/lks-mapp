# Карта УЛК МГТУ — Telegram Mini App

`index.html` в корне — собранное мини-приложение (GitHub Pages → бот @BMSTUMap_Bot, кнопка меню). Руками его не править.

Исходники в `src/`:
- `scans/f*.jpg` — сканы поэтажных планов (2600 px по ширине). Геометрия берётся из них.
- `floors.py` — что где: номера и вид помещений с примерными рамками (рамка служит только «зерном» для поиска реального контура), зоны коридоров `corr`, лестнично-лифтовые блоки `deco`, лифтовые холлы `st` («Холл 1/2» связывают этажи), входы, диагональные проходы `paths`, подписи, `erase` (прямоугольники на скане, где стереть крупный текст).
  Комнаты: `(номер, x0, x1, y0, y1, вид, псевдонимы)`; виды `room | wc | svc | area | place`. Этажи 10–11 хранят номера без префикса, префикс добавляется (`1011`).
- `gen.py` — трассировка: стены = тёмные линии скана без текста/сетки (векторизуются); помещение = реальная замкнутая область вокруг рамки (заливка с постепенным закрытием дверных проёмов, при слиянии с соседями — рамка); коридоры = свободное место в зонах `corr`; граф маршрутов = скелет коридоров + прямые «срезки» по видимости.
- `template.html` — страница (стиль ЛКС: чёрный фон, синий #0a52ad, Montserrat).
- `tg_extra.js` — интеграция с Telegram WebApp: expand, цвета, disableVerticalSwipes, `startapp=403` / `from_1101__to_403`.

Пересборка: `python3 src/build.py` из корня репозитория, затем коммит `index.html` и `src/`.
Этажи 4–11: `boxgen.py` — чистая схема на общей сетке (ряд аудиторий / коридор / ряд), аудитории не уже MINW, пустоты = некликабельные заглушки, на концах этажа коридор обходит блок буквой «П» (крайние крылья), одинокая аудитория в блоке = большой зал на всю высоту (646, 544…), крайние лестницы маленькие горизонтальные + 2 лифта под ними, центральная лестница убрана. Утверждено на 6-м этаже. Этажи 2–3: `build_mapped` — x из floors.py, y сжат по `YMAP`, свой контур `OUTLINES`, внутренние проходы `EXTRA_CORR`, атриум/зал `MAP_AREAS`. Этаж 4: `SQUEEZE` (верхний ряд раздвинут под башни) + `AREAS`.
Вид (по просьбе владельца): схема без стен — контур корпуса, коридоры и аудитории прямоугольниками на своих местах (края выровнены по рядам), стены скана не рисуются (`wl` пустой; `clean_walls`/`straight_walls` в `wallvec.py` оставлены на случай возврата).
Обозначения от владельца: лестницы и лифтовый холл показываются знаком «*|*» (лестница | лифтовый холл | лестница); у Электрозаводской — «Северный вход»; буфет 1-го этажа под 133.
