# Карта УЛК МГТУ им. Н.Э. Баумана

Интерактивная карта учебно-лабораторного корпуса: поиск аудитории и маршрут от входа или между аудиториями, все этажи 1а–11.
Работает как Telegram Mini App в боте @BMSTUMap_Bot и как сайт: https://mmizy98.github.io/lks-mapp/

Ссылки с готовым маршрутом: `https://t.me/BMSTUMap_Bot/<app>?startapp=403` или `?startapp=from_1101__to_403`.
Исходники и пересборка — см. `CLAUDE.md`.
